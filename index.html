About this tool

About the Data

This web app displays the Martian crater database compiled by Dr. Stuart Robbins and Dr. Brian Hynek. The initial publication for this work can be found in the following paper: A new global database of Mars impact craters ≥1 km: 1. Database creation, properties, and parameters.. The database has been updated several times, with the most recent iteration being available on Dr. Robbins' website.

Users of this tool should be aware of the caveats of the Mars crater database. These are discussed in a conference abstract and summarized on Dr. Robbins' website. We present this search tool without commentary on the quality of the database; it is left to the user to decide if the database is good enough for their usecase.

Usage

Filters are provided on the left hand side. Numeric data can be filtered by clamping with a range slider. Classification data can filtered via text input. Eventually, all valid inputs will be provided and selectable with small pie charts. Once the filters are set, they can be applied by clicking the "Update Filter" button.

The map and table update to show craters that match the selected filter. Users may scroll on the table horizontally to see additional columns and vertically to see additional rows. Only 25 rows are shown at a time for simplicity.
